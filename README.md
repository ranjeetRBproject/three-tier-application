\# Three-Tier Java React MySQL Application



\## Project Overview



This project demonstrates how to build and deploy a three-tier application using DevOps practices.



\### Application Components



\- \*\*Frontend:\*\* React

\- \*\*Backend:\*\* Java Spring Boot REST API

\- \*\*Database:\*\* MySQL



\### DevOps Tools



\- Git and GitHub for source control

\- Docker for containerization

\- AWS ECR for container image storage

\- Amazon EKS for Kubernetes orchestration

\- Amazon RDS for managed MySQL

\- GitHub Actions for CI/CD



\## Environments



\- QA: application testing and validation

\- PROD: production deployment after QA verification



\## Project Status



Initial repository setup. Application source code and CI/CD workflows will be added in subsequent steps.
